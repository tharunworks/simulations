Checksum digest vs HMAC signature vs checksum type
SHA-256(part bytes) is a digest; S3 recomputes it to detect changed bytes. HMAC-SHA256 signs the canonical HTTP request (including the chosen checksum header) to authorize it. Neither value is encrypted or decrypted. COMPOSITE combines per-part checksums for multipart uploads; FULL_OBJECT represents the entire object (for example CRC64NVME). The final multipart ETag is not necessarily a full-file MD5 or SHA-256. UNSIGNED-PAYLOAD in SigV4 is not the same as an unsigned x-amz-checksum-* header.
